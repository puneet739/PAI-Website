## About This Project

This is the official website for the Paragliding Association of India (PAI). The project was initiated and is maintained by Puneet Behl to provide a comprehensive platform for managing memberships, insurance policies, pilot ratings, and events for the paragliding community in India.

## Contributing

We welcome contributions from the community! If you'd like to contribute to this project, please:

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request

Please ensure all contributions maintain proper attribution to the original project creator, Puneet Behl.
